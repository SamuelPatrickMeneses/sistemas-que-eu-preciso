# Agente de IA integrado com Anytype

## O problema
Ter um agente de IA integrado com o Anytype (app de base de conhecimento/notes) com funcionalidades de edição de documentos tipo Word e PDFs.

## Contexto
Quero usar IA para trabalhar sobre meu conteúdo do Anytype e editar/manipular documentos Word (.docx) e PDFs.

## Ideia de solução (rascunho)
- Integração com a API/banco do Anytype para ler/escrever conteúdo.
- Capacidade de edição de documentos: .docx e PDF (criar, modificar, converter, extrair texto).
- Agente que combina as duas coisas: pega conteúdo do Anytype e gera/edita documentos.

## Alternativas atuais
- Copiar/colar manual entre Anytype e Word/Google Docs; usar IA em janela separada; ferramentas isoladas para docx/pdf.

## Notas
- Prioridade: média
- Data: 2026-08-18

## Critérios de "promoção" para projeto
- Verificar se o Anytype tem API pública/CLI e definir o escopo de "edição" de documentos (criar vs. alterar existente).
